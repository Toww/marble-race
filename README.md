# Marble Race

This is the final project from Bruno Simon's [Three.js Journey](https://threejs-journey.com/ "Three.js Journey"), combining some of the techniques learned through the course.

This project uses [Three.js](https://threejs.org/ "Three.js"), [React Three Fiber](https://r3f.docs.pmnd.rs/ "React Three Fiber"), [Drei](https://drei.docs.pmnd.rs/ "Drei"), and [Rapier](https://rapier.rs/ "Rapier") to handle physics.

Online version available at : [https://marble-race-iota.vercel.app/](https://marble-race-iota.vercel.app/ "Online version").

Many Thanks to Bruno Simon and the [Poimandres](https://pmnd.rs/ "Poimandres") collective for all their work !
